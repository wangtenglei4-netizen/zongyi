# 镜中局 · 本地原型

周五需求讨论用。一台电脑、一个浏览器标签页即可演示。黑白两队各有三名平民和一名潜伏在本队的对方卧底。抽签同时决定分队。

## 启动

macOS 可以双击「启动演示.command」，再打开下方地址。需要 Node.js 20.9 或以上；也可以在项目文件夹内运行：

```sh
npm ci
npm run dev
```

打开终端里显示的 `Local` 地址（默认是 http://127.0.0.1:3000）。结束演示时，在终端按 Control + C 停止。生产构建验证可运行 `npm run build`，规则测试用 `npm test`。

## 演示顺序

1. 默认打开大屏展示。选中格子再确认抽签，大屏显示占用情况。
2. 点「私密查看身份」看身份图标和提示文案；点「下一位」清除当前展示并切回大屏。
3. 八位嘉宾全部抽完后，进入「魔镜查验」。选择提问队伍、嘉宾并确认，每队一次。点「私密查看结果」查看是否为卧底。
4. 刷新页面会恢复抽签和查验进度；「重置本局」会重新洗牌。

身份图为临时图标，甲方素材确认后可替换。大屏和私密展示是同一页面的显示模式；这版用当前浏览器本地保存进度，仅供单标签演示，不提供设备同步或身份访问权限。正式录制版需要将身份数据和查验权限移到服务端。
